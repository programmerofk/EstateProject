# 🏠 Estate — Real Estate Landing Page

Современный лендинг агентства недвижимости с интерактивным каталогом объектов, тёмной темой и избранным.

## 🔗 Live Demo

**[Посмотреть сайт →](https://estate-project.vercel.app)**

## ✨ Функционал

- 🎨 **Светлая / тёмная тема** с сохранением выбора в `localStorage`
- 📱 **Адаптивная вёрстка** — desktop, tablet, mobile
- 🍔 **Мобильное бургер-меню** с плавной анимацией
- 🔍 **Фильтрация объектов** по типу (Houses / Villas / Apartments)
- ↕️ **Сортировка** по цене и названию
- 🪟 **Модальное окно** с деталями объекта
- ⬅️➡️ **Навигация между объектами** внутри модалки + счётчик
- ❤️ **Избранное** с счётчиком и отдельной секцией
- ✅ **Валидация формы** подписки с сообщениями об ошибках
- 🎬 **Анимация появления секций** при скролле (IntersectionObserver)
- ⬆️ **Кнопка «Наверх»**
- 📌 **Sticky-навигация** с тенью при скролле
- 🔗 **Плавный скролл** по якорным ссылкам

## 🛠️ Стек

- **HTML5** — семантическая разметка
- **CSS3** — Flexbox, Grid, CSS-переменные, media queries
- **Vanilla JavaScript** — без фреймворков
- **LocalStorage** — сохранение темы и избранного
